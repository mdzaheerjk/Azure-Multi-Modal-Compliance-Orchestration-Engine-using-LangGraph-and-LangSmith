# Azure-Multi-Modal-Compliance-Orchestration-Engine-using-LangGraph-and-LangSmith
An automated Video Compliance QA pipeline using LangGraph audits videos with RAG against regulatory rules. It uses Azure Video Indexer + OCR, Azure AI Search + embeddings, and GPT-4o to detect violations and generate structured JSON reports, with LangSmith tracing and App Insights monitoring.
